02 / 대표 프로젝트

직접 쓰고 있는 서비스를 만듭니다

대표 프로젝트 OpicTutor와, 하루 만에 초기 기업을 만든 해커톤 프로젝트입니다.

FEATURED · AI 교육 플랫폼 · 팀 프로젝트

오픽 튜터
OpicTutor

진행자 린(Rin)의 영어 질문을 듣고 음성으로 답하면, 실전과 같은 8문항 모의 인터뷰 뒤에 ACTFL 루브릭과 RAG를 근거로 예상 등급(NL–AL)과 맞춤 교정 카드를 돌려주는 OPIc 학습 플랫폼입니다.

● REC demo.gif

문제 정의

OPIc은 말하기 시험이라 채점 기준이 애매하게 느껴지고, 내 답변이 어느 수준인지 언제 어디서나 객관적으로 피드백받기 어렵습니다.

대상 사용자 & 핵심 경험

OPIc·토스 영어 등 말하기 시험 수험생. AI가 답변의 객관적 수준을 진단하고, 대화형 피드백으로 답변을 한 단계씩 끌어올려 목표 점수에 닿도록 돕습니다.

내 역할 — 기획·RAG 데이터·TTS·프론트엔드 전 화면

설계 · 협업 구조

요구사항 v2와 API 명세를 작성하고, AI 에이전트 병렬 개발을 위해 에이전트별 프롬프트·계약(contracts)·머지 전략·PC 3대별 런북을 설계했습니다. 이후 채점 항목·태그·FACT 서술형 피드백을 담은 v3로 갱신했습니다.

RAG 코퍼스

NL–AL 채점용 루브릭 9종, 업그레이드 패턴 8종, 문제은행 30문항, 그리고 12문항 × 9등급의 파일럿 대조 세트(원문·STT 버전)와 빌드·검증 스크립트를 구축했습니다.

TTS 파이프라인

Colab OmniVoice로 진행자 음성 242개(약 43분)를 생성·반입하고, 텍스트 해시 검증·세션 준비 핸들러·내보내기/가져오기 스크립트, 진행자 캐릭터와 오디오 플레이어를 만들었습니다.

프론트엔드 M2

로그인→설정→준비→시험→채점 중→결과 전체 화면을 구현했습니다. 서버 확인 전에는 넘어가지 않는 문항 상태 머신, 업로드 재전송(1·2·4초), 새로고침 복구, 근거 3단 결과 리포트, 키보드·aria-live 접근성까지 다뤘습니다.

품질 · 버그

빠른 연속 재생 시 이전 재생의 AbortError가 다음 재생을 실패시키던 경쟁 조건, 음성 재등록 시 SameFileError 등을 Playwright 완주 테스트에서 찾아 고쳤습니다. pytest와 빌드 검증을 함께 통과시켰습니다.

문서 · 데모

README에 데모 미리보기(GIF·MP4)와 핵심 흐름 요약을 정리했습니다. 커밋마다 AI 활용 여부를 AI-assisted로 명시해 기여 과정을 투명하게 남겼습니다.

HACKATHON · 1:1 학습 매칭

전공한시간

[HUSS] 2026 AI START-UP SPRINT — 하루 만에 초기 기업 만들기

같은 캠퍼스(또는 편입 준비) 튜터와 학습자를 이어 주는 1:1 학습 매칭 서비스입니다. 수업 탐색, 추천 이유 제시, 협의·예약, 교육자·운영자 화면까지 하루 안에 구현했습니다.

역할 — Agent AI를 활용해 서비스를 개발했습니다.

결과 — 원하는 품질까지는 닿지 못했지만, 개선하고 발전시킬 방향을 많이 찾았습니다. 우선 파일과 코드 정리부터 진행합니다.

기술

Next.js · React · TS NestJS FastAPI · Pydantic PostgreSQL · pgvector Supabase 작업 큐 + Python worker 서비스별 개별 배포

발전 아이디어

  1. AI 출제 당일 퀴즈 — 커리큘럼에 맞는 시험을 AI가 등록하고 당일 공개해 실력 허위 등록을 막습니다.
  2. 수요 분석(RAG) — 학습자가 원하는 과목·분야를 분석해 튜터에게 알려 줍니다. 유료 튜터에게는 요청 항목과 소비 트렌드를 제공합니다.
  3. 블록체인 경력 증명서 — 과외 이력을 경력으로 쓸 수 있도록 증명서를 발급하고, 후기·테스트 결과에 따라 브론즈·실버·골드 토큰 뱃지를 부여합니다.
  4. 영지식 증명 신원 확인 — 민감 정보를 드러내지 않고 "원하는 학교·학과 학생"임을 대학과 연계해 증명합니다.
  5. 커리큘럼 자동 생성 — 유료 서비스로 제공합니다.
